# Security Policy

## Supported Versions

This is a personal portfolio site. Only the version currently deployed at
[arnon.dev](https://arnon.dev) is supported — it always tracks the `main` branch.

## Reporting a Vulnerability

Please report vulnerabilities privately to **me@arnon.dev**, or through
[GitHub's private advisory form](https://github.com/arnonrdp/Portfolio/security/advisories/new).
Do not open a public issue.

Include the steps to reproduce and what an attacker could do with it. I aim to
reply within a few days.
